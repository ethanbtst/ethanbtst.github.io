Homelab

This is the page for my tiny homelab which happens to host this website, gets used for my university work and many more things.

Hardware

  • CPU: Intel i7-11800H (soldered to motherboard)
  • Motherboard: Erying M-ITX B560i
  • GPU: EVGA NVIDIA 3060 Ti FTW3
  • Memory: 2 x 32GB Crucial Pro 3200MHz
  • Storage:
    • 2 x 4 TB WD Red Plus NAS HDD
    • 1 x 1 TB Kingston M.2 SSD
    • 1 x 256 GB Kingston M.2 SSD

Current Software Setup

Proxmox

Proxmox is the virtualization platform of choice, occupying the 1TB SDD which should be large enough to hold a good number of virtual machines.

Proxmox Backup Server is used for taking snapshots of my VMs and backing up the VMs. Not ideal in an ideal spot as PBS is running on the Proxmox machine that it takes the backups of.

Truenas

NAS software of choice and installed onto the 256GB SSD which then gets passed to the VM in Proxmox. The data vdev consists of the 2 4TB HDDs which are striped (good heavens theres no redundency!) and also passed to the VM by passing the SATA controller to the VM.

All useful data is put in its own dataset, may have some form snapshotting and made accessible through NFS and SMB.

Truenas was the former hypervisor of choice before I switched to Proxmox. Since it was setup on its own hardware and simply passed through there is always the option to move it back to its dedicated machine.

Tailscale

The VPN that easily lets me access what I need

Virtual Machines

  • Lantern - Arch Linux

    • The first and most general of the VMs setup. Runs a multitude of things such as Nextcloud for cloud storage I use for school, Jellyfin for media streaming, Immich for photo management and more.

    Given the most resources as I use this for some remote work like machine learning, a shared Jupyter Notebook server and RStudio that need I and others can use.

  • Lighthouse - Debian Forky

    • The networking focused VM that runs

    • Pi-hole: Network ad blocker and DNS
    • Unbound: Recursive DNS resolver
    • Caddy: Reverse proxy
  • web02 - Debian Forky

    • Current host of this website, not much else

Future Plans

There are a couple things that I would like to improve. I would like to move the networking stuff onto its own machine and I'm aiming to get a Lenovo Thinkstation Tiny that has a PCIe slot, installing a multiport NIC and virtualizing something like pfsense and the existing lighthouse VM.

Better backup and more storage as well would be nice to have. Everything lives on a single system and could go up in flames.
